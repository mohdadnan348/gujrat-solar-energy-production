HR MODULE FILES

This folder contains the HR dashboard and the complete module page files copied from the Admin module set: Attendance, Customers, Employees, Invoices, Leads, Leaves, Notifications, Payroll, Quotations, Reports, Settings, and Tasks.

The current application routes may still import shared Admin page components so that the same UI and workflows are reused. Backend authorization and HR ownership filters must enforce that HR can access only records assigned to/created by that HR account.
